# AngularJS to-do list

Learning demo created by Estefanía Fdez Muñoz. Add tasks, mark them complete,
show or hide the list, and remove completed tasks. Tasks are held in memory and
are lost on refresh.

## Run

```bash
python3 -m http.server 8000
```

Open http://localhost:8000. No build or account is required.
AngularJS 1.8.3 is vendored in `js/angular.min.js` for offline use.

AngularJS is end-of-life. This project preserves the original framework as a
learning example, not a recommendation for new production applications.
